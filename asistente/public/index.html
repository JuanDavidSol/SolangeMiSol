🔑 ¿Tienes tu propia API de Gemini? Configurar

Puedes usar tu propia clave para conversar con Snoopy. Es opcional y no necesitas contraseña de administrador.

Opcional: el navegador guardará la clave sin cifrado adicional. No la guardes en equipos compartidos. En otro dispositivo tendrás que introducirla de nuevo.

Pega tu clave de Gemini. Puedes pulsar «Probar conexión» directamente. La clave solo se recordará en este navegador si marcas la casilla; de lo contrario se borra al recargar.

La clave viaja por HTTPS a este servidor y de allí a Gemini en cada mensaje. Quien administra el servidor debe ser de confianza; el uso de tu clave puede consumir cuota o generar cargos.

✓ Gemini activado (conexión no verificada).

Puedes escribir o pulsar 🎤 para conversar con Snoopy. Al cambiar de pestaña se pausa y al volver se reanuda; Alt + M permite pausar manualmente. El navegador podría usar su servicio de reconocimiento de voz para procesar el audio. Los mensajes enviados con tu API se procesan en Gemini; evita compartir datos personales o secretos.
