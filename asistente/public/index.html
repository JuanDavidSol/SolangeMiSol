🔑 ¿Tienes tu propia API de Gemini? Configurar

Puedes usar tu propia clave para conversar con Snoopy. Es opcional y no necesitas contraseña de administrador.

Pega tu clave de Gemini. Puedes pulsar «Probar conexión» directamente: no hace falta activarla primero. No guardamos la clave y tendrás que volver a pegarla al recargar.

La clave viaja por HTTPS a este servidor y de allí a Gemini en cada mensaje. Quien administra el servidor debe ser de confianza; el uso de tu clave puede consumir cuota o generar cargos.

Soy un asistente virtual. Los mensajes enviados con tu API se procesan en Gemini; evita compartir datos personales o secretos.
